# Sakuga — brighter atmosphere refinement

Current brief: preserve the approved kinetic design, two self-hosted font families, useful content and working flows. Make the existing pink/violet/blue gradient much more present; replace synthesized sounds with a licensed premade collection; use the selected anime cover as a blurred detail backdrop that fades into the brighter gradient as the visitor scrolls. This is amplification of the shipped world, not a replacement layout or new typography system.

Operate mode. Artwork supports discovering a show and recording progress; navigation, source links, season selection, session persistence and list editing remain primary. No decorative copy or unsupported personal/catalog claims are added.

The full-viewport gradient stays fixed and static so long pages retain color. Brightened section surfaces, lighter readable secondary text, a more translucent header, native scrollbar/caret treatments, stronger link states, season-picker tint and a visible carousel timer carry the same palette. Anime art is fixed behind content, blurred once and shaded for readable text. Only opacity changes with scroll, coalesced into one requested frame; there is no persistent background render loop. Missing or hidden source artwork leaves the gradient intact. Reduced transparency hides the backdrop.

Sounds use three unmodified CC0 Kenney WAV files, bundled locally with provenance. Preserve mute and the existing preference schema. No oscillators, hover sounds, music or new sound-related UI copy.

Verify once in a batched desktop/mobile browser round, correct all findings together, then use one confirmation round. Preserve source truth and distinguish local fixture checks from deployment and live runtime evidence.
