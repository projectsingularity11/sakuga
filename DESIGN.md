# Sakuga — suspended cinema

The current brief replaces the earlier midnight-cinema layout. The homepage remains an operational anime-discovery surface: real featured artwork, direct catalog and library actions, and independent popular, release-year and upcoming queries. Reference points are Unseen's material and motion, Miruro's artwork density, and Lusion's immersive composition. Preserve Sakuga's original hand-inked eye/play mark.

Use a near-black graphite canvas, warm ivory text and a persimmon accent. Space Grotesk supplies the distinctive display and navigation voice; Manrope handles compact product text. Self-host both. Use large, legible posters and a deliberately offset feature poster in a framed artwork composition. No promotional slogans, decorative statistics or catchphrases. Controls should name their action.

Liquid glass belongs on the suspended navigation, search dock, sidebar and small sound controls. Use translucent surfaces, fine reflected edges, inset highlights and backdrop blur; supply opaque fallbacks and respect reduced transparency. Light/dark/system and a user's saved accent remain functional across public and private pages.

Mouse movement shifts the feature lighting; scrolling moves the background plane and updates a thin progress line. Keep these changes out of React renders. Coarse pointers do not drive the lighting, and reduced motion disables these effects, animated hover and smooth scrolling. Essential links and list actions remain visible without hover.

Mobile has a two-column cover grid, a full-width search row and a collapsible navigation. The workspace sidebar can collapse to an icon rail on desktop and starts closed on small screens unless the user has chosen otherwise. Discovery filters are explicitly collapsible. Never allow search suggestions to hide behind the feature artwork.

Sound is an opt-in product control: quiet click, hover and selection sounds, plus an original synthesized 72 BPM lo-fi loop. Separate toggles remember their state on this device. The audio engine persists in the root layout across internal navigation, pauses in hidden tabs and requires a browser-permitted user gesture. Use a compact icon dock; no explanatory marketing copy.

Verified AniList PREQUEL/SEQUEL relationships join narrative seasons and parts across TV, web, special, OVA and film formats. Music videos remain separate. Side stories, spin-offs and title similarity alone never establish a series. Search and library pagination operate on shows. Public and private show pages select a season with a dropdown; legacy season links resolve to the show with that season selected. Saved progress, scores, notes and collection membership retain the original season's anime ID. Always key the editor by the selected season.

Artwork and metadata are source-backed. Prefer measured high-resolution originals but retain real smaller originals when HD art does not exist. Missing covers use original Sakuga background artwork explicitly marked unavailable; do not label that background as the anime's poster. Names default to official English, then romaji. Source English synopses take priority; otherwise label release facts honestly. Direct verified MAL/IMDb/trailer links take priority, with clearly named searches for missing matches. Never manufacture metadata or universal coverage claims.

Verify 375, 390, 768, 1280 and 1440 pixel widths together, including keyboard, contrast in both appearances, missing artwork, search races, season changes and authenticated homepage returns. Fixture screenshots demonstrate layout only; production claims need remote evidence.
