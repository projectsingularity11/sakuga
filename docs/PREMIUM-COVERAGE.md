# Premium visual and catalog coverage update

Implemented a poster-led feature composition, selective translucent navigation/dock surfaces, warm accent/reflected backgrounds, typographic hierarchy, shared source actions and responsive artwork layouts. Contrast/keyboard behavior are retained. Glass has solid-color and reduced-transparency fallbacks.

The latest request for universal pictures supersedes the earlier strict HD-only display policy. Smaller real originals are retained. The worker measures available candidates and selects the largest; failed lookups no longer erase an existing valid cover. Anime-Planet and aniSearch image hosts used by the original licensed metadata snapshot are now explicitly allowed alongside AniList/MAL/Kitsu. The restoration command is reproducible via `npx tsx scripts/restore-artwork.ts --file=/path/to/anime-offline-database-minified.json --sql-dir=/tmp/restore` or normal operator credentials without --sql-dir.

Every card and dossier now has an image presentation. **That does not mean every record has genuine title-specific cover art:** the restored snapshot has 20,071 picture URLs among 20,153 published works (counts vary as provider moderation runs). The remaining 82 records had no source picture, including older shorts. Those use visibly labeled original Sakuga artwork; no fake poster is attributed to them. URL coverage is not a claim that every upstream URL was downloaded and audited. The browser fallback handles source failures without a blank rectangle.

Source-linked trailer URLs are ingested from AniList and Kitsu. Validated MAL listing links use existing stable mappings. IMDb IDs can be enriched through exact Wikidata MAL cross-references after checking the identities of Wikidata properties P4086 and P8729; ambiguous mappings are skipped and source provenance is stored. Where a listing/trailer is unknown, the action is labeled as a search. Search links are not claimed as verified listings or existing trailers. Some obscure anime have no IMDb entry or trailer at all.

Official English names remain English-first, with original/romaji fallbacks where an official English name is absent. AniList and Kitsu English metadata enrichment is ongoing. English story synopses are shown where available; missing or detected non-English text is replaced in the UI by a labeled factual release summary using known format/year/episodes/studios/genres. This is not a claim that every work has an official English plot synopsis or licensed English title. A translation provider/editorial translations would be needed for full translated-name coverage.

Checks: 36 deterministic tests passed, including link validation/search encoding, English fallbacks, preservation of lower-resolution real originals, existing persistence/ownership and search ranking. Twenty-five browser checks passed across 375, 390, 768, 1280 and 1440 widths; four focused final checks passed after the visual corrections. Fixtures exercise both genuine local curated art and missing-art behavior. Production build, lint and TypeScript passed. Authenticated end-to-end browser flows were not newly claimed; existing backend tests were retained.

No user accounts, libraries or collections were reset. No account-deletion capability or payment configuration was enabled by this update.

The verified link importer also backfills missing English names from the matched Wikidata entity’s English label, with source provenance. It never overwrites an existing English title or IMDb match. The additional integration test verifies client execution is denied and service-role enrichment is idempotent.

Final appearance verification also covers light-mode glass/source-control contrast. Bulk title enrichment is followed by fresh catalog statistics; the table auto-analyze threshold is reduced so metadata refreshes do not leave search plans stale. Exact provenance checks imported 5,227 IMDb mappings across the whole catalog; publication filtering makes the public count lower. A subsequent AniList/MAL/Wikidata English-label pass filled more missing source-backed names without replacing existing names.
